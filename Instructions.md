# Reproducing the Experimental Results

This document describes the steps required to reproduce all tables and figures reported in the paper.

## Prerequisites

- Python 3.x
- All required Python dependencies installed.
- The benchmark log directories should be available before running the scripts.

---

# Directory Naming Convention

The scripts expect the experimental log files to be organized in specific directories. The directory names are used throughout the workflow and should **not** be changed unless the scripts are modified accordingly.

The expected directory structure is:

| Model / Configuration | Directory Name |
|-----------------------|----------------|
| GPT-OSS-20B (Local LLM) | `gpt20b` |
| GPT-OSS-120B (Amazon Bedrock) | `gpt120b` |
| Claude (Amazon Bedrock) | `claude` |
| Qwen-30B (Amazon Bedrock) | `qwen30b` |
| Maverick (Amazon Bedrock) | `maverick` |
| NoLemma Ablation | `NoLemma` |
| NoGamma Ablation | `NoGamma` |

### Notes

- Log files generated using the **local GPT-OSS-20B model** should be stored in the `gpt20b` directory.
- Log files generated using **Amazon Bedrock models** should be stored in their respective directories (e.g., `claude`, `maverick`, etc.).
- Each directory should contain log files generated by **only one model/configuration**.
- The directory names should exactly match those listed above, as the scripts expect these names.

# Generated CSV Files

The intermediate CSV files produced by the scripts are used as inputs for generating the tables and figures in the paper.

## 1. `lemma_analysis.csv`

This file summarizes the lemma generation and verification process for each benchmark.

| Column | Description |
|--------|-------------|
| **File** | Benchmark name. |
| **Distinct Lines** | Number of **unique generated lemmas** that successfully passed the preprocessing stage (e.g., syntax validation and lightweight testing) and were subsequently checked by the SMT solver. |
| **Cex Count** | Number of generated lemmas that were falsified by the fuzzing solver (i.e., a counterexample was found). |
| **Lemma Verified Count** | Number of generated lemmas that were successfully verified by the fuzzer. |
| **UnsatCore Count** | Number of verified lemmas that appear in the final UNSAT core. These lemmas are presented to the human validators. |
| **Total Lemmas** | Total number of lemmas generated by the LLM before any preprocessing or filtering. |
| **Failed Prepass** | Number of generated lemmas rejected during preprocessing (e.g., syntax errors or failing lightweight validation) before being submitted to the SMT solver. |

## 2. `<model>Timings.csv`

Examples include:

- `gpt20bTimings.csv`
- `NoGammaTimings.csv`

Each row corresponds to one benchmark.

| Column | Description |
|--------|-------------|
| **File** | Benchmark name. |
| **Total Time** | Total time required to solve the benchmark. |
| **Z3 Time** | Time spent inside the SMT solver (Z3). |
| **Fuzzer Time** | Time spent validating lemmas by fuzzer |
| **LLM Time** | Time spent querying the language model to generate candidate lemmas and updating them |
| **Status** | Final result of the benchmark (e.g., `SAT`, `UNSAT`, or `UNKNOWN`). |

## 3. `results<Model>.csv`

Examples include:

- `resultsgpt20b.csv`
- `resultsgpt120b.csv`
- `resultsclaude.csv`
- `resultsmaverick.csv`
- `resultsqwen30b.csv`
- `resultsNoLemma.csv`
- `resultsNoGamma.csv`

Each row corresponds to a single benchmark and summarizes the final verification outcome for a particular model or configuration. These CSV files are used to generate Tables 3 and 4, compute the virtual best solver, and produce the evaluation figures.

| Column | Description |
|--------|-------------|
| **filename** | Benchmark name. |
| **category** | Final verification result for the benchmark (e.g., `UNSAT`, `SAT`, or `UNKNOWN`). |
| **z3_time** | Total time spent by the SMT solver (Z3) while verifying the benchmark. |
| **fuzzer_time** | Total time spent validating lemmas using fuzzer. |
| **num_iterations** | Number of iterations that were done to get a verdict by running the experiment for a maximum of 3 iterations normally (10 times for local hosted LLM to show that number of iteration affect the performance of the tool because of difference in response of LLMs). |

# Step 1: Generate Lemma Analysis

**Command syntax**

```bash
python3 genLemmaResultsRebuttal.py <path_to_directory_containing_log_files>
```

Run the command once for each model directory.

**Example**

```bash
python3 genLemmaResultsRebuttal.py ../gpt20b
python3 genLemmaResultsRebuttal.py ../gpt120b
python3 genLemmaResultsRebuttal.py ../claude
python3 genLemmaResultsRebuttal.py ../qwen30b
python3 genLemmaResultsRebuttal.py ../maverick
python3 genLemmaResultsRebuttal.py ../NoLemma
python3 genLemmaResultsRebuttal.py ../NoGamma
```


This script generates the `lemma_analysis.csv` file for each model.

---

# Step 2: Generate Per-Model Result CSVs

**Command syntax**

```bash
python3 generateResult.py <path_to_directory_containing_log_files> <output_csv_file>
```

Run the following commands:

```bash
python3 generateResult.py ../gpt120b resultsgpt120b.csv
python3 generateResult.py ../gpt20b resultsgpt20b.csv
python3 generateResult.py ../claude resultsclaude.csv
python3 generateResult.py ../maverick resultsmaverick.csv
python3 generateResult.py ../qwen30b resultsqwen30b.csv
python3 generateResult.py ../NoLemma resultsNoLemma.csv
python3 generateResult.py ../NoGamma resultsNoGamma.csv
```

These CSV files are used for generating Tables 3, 4, and several figures.

# Complete Workflow

The complete sequence of commands to reproduce all tables and figures is shown below.

```bash
# Generate lemma analysis
python3 genLemmaResultsRebuttal.py ../gpt20b
python3 genLemmaResultsRebuttal.py ../gpt120b
python3 genLemmaResultsRebuttal.py ../claude
python3 genLemmaResultsRebuttal.py ../qwen30b
python3 genLemmaResultsRebuttal.py ../maverick
python3 genLemmaResultsRebuttal.py ../NoLemma
python3 genLemmaResultsRebuttal.py ../NoGamma

# Generate summary CSVs
python3 generateResult.py ../gpt120b resultsgpt120b.csv
python3 generateResult.py ../gpt20b resultsgpt20b.csv
python3 generateResult.py ../claude resultsclaude.csv
python3 generateResult.py ../maverick resultsmaverick.csv
python3 generateResult.py ../qwen30b resultsqwen30b.csv
python3 generateResult.py ../NoLemma resultsNoLemma.csv
python3 generateResult.py ../NoGamma resultsNoGamma.csv

# Compute virtual best
python3 virtualbest.py

# Generate Table 4
python3 genTable4.py

# Generate bar graphs
python3 drawBarGraph.py
python3 drawBarGraphB.py

# Generate line graph
python3 drawLineGraph.py resultsgpt20b.csv

# Generate timing statistics
python3 genTimingResults.py ../gpt20b
python3 genTimingResults.py ../NoGamma

# Draw timing comparison
python3 drawPlotTimings.py gpt20bTimings.csv NoGammaTimings.csv "Total Time" --bench "File"

# Generate remaining tables
python3 genTable5.py
python3 genTable3.py
```
